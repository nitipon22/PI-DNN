This study proposes a Physics-Informed Deep Neural Network (PI-DNN) for battery Remaining Useful Life (RUL) prediction by combining deep learning with monotonicity constraints.

The proposed model was evaluated using the publicly available HNEI lithium-ion battery dataset. The repository contains the following Python scripts:

- `nn.py`: Implementation and evaluation of PI-DNN, DNN, and other neural network models.
- `nonnn.py`: Implementation and evaluation of non-neural-network models, including traditional machine learning models.
- `externalall.py`: Experiments evaluating model performance on an additional battery dataset.
